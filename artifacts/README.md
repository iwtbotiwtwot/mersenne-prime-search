# Artifacts

The first frozen SLC export is installed under
[`exports/SAM_MP_S8_MP_S9_V1`](../exports/SAM_MP_S8_MP_S9_V1/README.md).
This directory remains reserved for future exact execution and replication
receipts.

Future immutable bundles belong in versioned subdirectories. Every bundle must
include its manifest, file hashes, source revision, execution command, and
result state. Scratch data belongs outside version control or under ignored
`artifacts/work/`.
